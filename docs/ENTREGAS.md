# Entregas (el único lugar para IDs y recursos)

Aquí se apunta **todo lo que llega del lado creativo** (Gemini, amigos).
Claude lo lee de aquí para conectarlo al código. Si no está aquí, no existe.

Cómo rellenar:
- Pega el **ID numérico** (solo los números) en la columna ID.
- Pon el **dueño**: `JZnoalive` o `Grupo` (debe ser el mismo dueño que el juego).
- Cambia `⬜` por `✅` cuando esté hecho y probado en Studio.
